# Jira app install (GET)

- **Method:** `GET`
- **Path:** `/apps/jira/install`
- **Tag:** `jira`
- **operationId:** `get_apps-jira-install`

## Description
Entry point for installing the Jira app.

## Responses
### 200
OK

## Example cURL Request
```bash
curl -X GET \
  'https://api.securityscorecard.io//apps/jira/install' \
  -H 'Authorization: Token <YOUR_API_TOKEN>'
```
